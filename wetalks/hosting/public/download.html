Install in four steps

1. Download the file

Tap Download APK. If your browser warns that this type of file can harm your device, that is Android's standard message for any app installed outside Google Play.

2. Open it

Tap the downloaded file. When Android asks, allow your browser to install apps ("Install unknown apps"), then go back and tap Install.

3. Allow notifications

Open WeTalks and allow notifications so calls and messages can reach you. On some phones also set battery to "No restrictions" and enable Autostart.

4. Create your account

Sign up, then open Settings → Privacy & security and create a key backup.

Verify your download (optional)

Check that the file wasn't altered. The SHA-256 above must match the file you downloaded:

sha256sum WeTalks.apk        # Linux / Mac
certutil -hashfile WeTalks.apk SHA256   # Windows

Releases are signed with the same key every time. Android refuses to install an update signed by anyone else.
