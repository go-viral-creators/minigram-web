Build on WeTalks

A small, friendly REST API to send one-time codes, alerts and follow-ups to people on WeTalks. Per-app keys, clear limits, and users always in control.

Open developer portalRead the docs

Send in one request

POST a message or a verification code with a plain JSON body. No SDK needed.

Codes done right

WeTalks generates the code, delivers it and checks it. Your server never has to store or see the code.

People stay in control

Every message is labelled with your app name. Users can switch service messages off or block your app, and we enforce it in the database rules.

Secure by design

Keys are stored as hashes, shown once, and can be revoked instantly. Every call is rate limited and logged for you.

Works from anywhere

Plain HTTPS and JSON. Examples for curl, Node.js, Python and PHP in the docs.

Free to start

Free plan with generous daily limits. Create an app and a key in under two minutes.

Quickstart

From zero to a delivered message in 3 steps

Create an account

Sign up in the portal with your email and verify it.

Create an app and key

Name your app, then create an API key. Copy it, it is shown once.

Send a message

Call the API with the key and a WeTalks username. It shows up in the person's service inbox.

curl -X POST https://wetalks.fireclashpro.com/api/v1/messages \
  -H "Authorization: Bearer wt_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"to":"@asha","title":"Order shipped","text":"Your order #1234 is on the way","kind":"alert"}'
